Penyelesaian

Variabel
x=Harga satuan jam HDD
y=Harga satuan lampu otomatis

Model Matematika
x + y = 170.000
x + 2y = 190.000

Eliminasi y
x + y = 170.000 |x2| 2x + 2y= 340.000
x +2y= 190.000 |x1| x + 2y= 190.000
________________________________________-
x = 150.000
Subtitusi
x + y= 170.000
150.000 + y= 170.000
y= 170.000 - 150.000
y= 20.000

Kesimpulan
Jadi, harga satuan dari jam HDD adalah Rp. 150.000,
sedangkan harga satuan dari lampu otomatis adalah Rp. 20.000
