Penyelesaian

Variabel
x = Harga satuan lampu kipas
y = Harga satuan kipas

Model Matematika
3x + y = 155.000
2x + 3y = 185.000

Eliminasi y
3x + y = 155.000 | x3 | 9x + 3y = 465.000
2x + 3y = 185.000 | x1 | 2x + 3y = 185.000
________________________________________ -
7x = 280.000
x = 280.000 / 7
x = 40.000

Substitusi
3x + y = 155.000
3(40.000) + y = 155.000
120.000 + y = 155.000
y = 155.000 - 120.000
y = 35.000

Kesimpulan
Jadi, harga satuan dari lampu kipas adalah Rp40.000, sedangkan harga satuan dari kipas adalah Rp35.000.
